# Nicoli Santana Silva | Nutricionista

Site profissional de apresentação e currículo de Nicoli Santana Silva.

## Tecnologias

- HTML semântico
- CSS responsivo
- JavaScript nativo

O projeto não precisa de instalação, dependências ou etapa de build. Para visualizar localmente, abra `index.html` em um navegador. Fontes e imagem são carregadas de serviços externos, então precisam de conexão com a internet.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie os arquivos deste projeto para a raiz do branch `main`.
2. No repositório, abra **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha o branch `main` e a pasta `/(root)`, depois salve.
5. Aguarde a publicação. O endereço do site aparecerá nessa mesma página.

Como `index.html` está na raiz, o GitHub Pages pode servir o site diretamente, sem workflow de build.
